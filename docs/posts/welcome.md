# 欢迎来到 perwebsite

## 为什么建站

很早之前就想拥有一个小小的、属于自己的角落，把散落在不同地方的项目、随笔和想法沉淀下来。GitHub Pages 提供稳定的免费托管，VitePress 又把"写 Markdown → 生成静态站点"这件事变得极其轻量——只要执行 `npm run docs:dev`，本地就能实时预览；再敲一次 `npm run docs:build`，一行命令即可产出可直接部署的产物。两者结合，让"建站"不再是一项需要长期投入的工程，而更像是写代码时顺手就能做的事情。

## 未来写什么

未来这里会慢慢积累三类内容，希望每一篇都经得起时间：

- **项目复盘**：踩过的坑、做过的取舍、值得记录的工程细节
- **学习笔记**：读到的论文、用过的库、解开过的 bug、总结过的范式
- **杂谈随想**：技术之外的观察、读书摘抄、生活片段、偶发的灵感

我不追求更新频率，只追求**值得写**——宁可一周不发，也不发让自己后悔的内容。

## 欢迎订阅

如果你也对上面这些话题感兴趣，欢迎通过 RSS 订阅本站（订阅功能稍后开启），或者直接到 GitHub 上 Watch 这个仓库。如果你发现错别字、技术错误，或者只是想打个招呼，欢迎随时提 issue，我会认真阅读每一条反馈。
