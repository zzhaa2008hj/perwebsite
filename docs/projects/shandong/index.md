# 山东省数据治理平台

## 简介

山东省政务数据治理与流通平台，整合 9 种数据源，完成 58 项优化任务，支撑省级政务数据流通。包含数据集成、任务调度、数据同步等多个子系统。

## 技术栈

- **数据集成**: ChunJun（分布式数据集成框架，基于 Apache Flink）
- **任务调度**: Taier（分布式任务调度系统）
- **后端**: RuoYi-Vue PostgreSQL 版（Java + Spring Boot）
- **前端**: Vue 3 + Vite
- **数据库**: PostgreSQL

## 核心功能

- 多源异构数据整合
- 数据同步与 ETL
- 任务分布式调度
- 政务数据流通支撑
