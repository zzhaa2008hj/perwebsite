# 关于我页面重新设计

## 背景

当前 `docs/about/index.md` 页面描述的是"前端工程化+开发者体验"方向的工程师，与实际背景（后端架构+AI工程化）严重不符，且未承载商业转化功能。

## 目标

- 目标访客：潜在甲方（技术负责人/CTO级别），重点B2B合作转化
- 访客看完后：直接联系 或 通过内容建立信任后再联系
- 页面调性：务实可信赖 + 有温度的技术人

## 设计方案

### 整体结构

```
[Hero区]  一句话 + 身份定位 + 核心数字
     ↓
[我能帮你]  痛点场景 → 对应能力 → 可量化成绩
     ↓
[经历]  时间线（精简到3段）
     ↓
[技能栈]  表格形式，精简版
     ↓
[内容产出]  文章+开源项目的信任背书
     ↓
[CTA]  直接联系 + 项目页/文章页引导
```
