## 关于我

我是一名专注于前端工程化与开发者体验的全栈工程师，日常工作围绕 **Web 静态站点、内容平台、可视化工具** 三条主线展开。我喜欢把重复性的操作抽象成可复用的脚本或流水线，让团队里每个人都能把精力放在真正有创造力的事情上。

我长期关注 **Vite / Vue / TypeScript / Node.js** 生态的演进，同时也保持对 Linux、容器化与 CI/CD 工具链的兴趣。近几年我的主要精力花在了把团队从“手动部署”逐步迁移到“PR 即发布”的自动化流程上，过程中踩过很多坑，也沉淀了不少可复用的模板与文档。
